# Zomato Restaurant Analysis

# Overview

A data analytics project focused on analyzing Zomato restaurant data to identify insights related to "ratings, customer engagement, cuisines, locations, pricing, and online ordering.

The project was developed using MySQL and Power BI.

# Tools Used
* MySQL – Data cleaning, SQL queries, and analysis
* Power BI – Dashboard development and visualization
* SQL – Business insights and data analysis

# Dashboard
The Power BI dashboard includes:
* Restaurant KPIs and overall analysis
* Top-rated and most-voted restaurants
* Popular cuisines and restaurant types
* Rating and customer engagement analysis
* Location-wise restaurant performance
* Cost and pricing analysis
* Online ordering analysis

# Key Insights
* Identified popular restaurant locations and cuisines.
* Analyzed customer engagement using votes and ratings.
* Compared restaurant costs across restaurant types.
* Examined online ordering availability by location.
* Analyzed the relationship between restaurant ratings and pricing.
